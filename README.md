## Sortsy — the product from last year

[sortsy.ai](https://sortsy.ai) is an AI file organizer. It reads a messy folder, understands the files, and proposes a clean structure. I worked on it at CoalDev from July 2025 to September 2026.

The product source is private. What I owned:

- Django REST API, PostgreSQL, Redis, Celery, and WebSockets
- PySide6 desktop agent (scan, review, apply)
- Amazon Bedrock captions indexed in Qdrant for semantic search

[Open the product](https://sortsy.ai) · [Read the case study](https://github.com/HarisUmer/sortsy) (architecture only, no proprietary code). Happy to walk through the codebase in a call.

## Aniga — Android shelf

A personal shelf for anime, manga, manhwa, and manhua. Ratings train what to open next, the reader loads the chapter, and a link shares that taste as a report a friend can open. Android app, Spring Boot API, PostgreSQL.
